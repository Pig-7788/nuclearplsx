## 📖 项目简介

「辟谣者联盟：核能纪元」是一款零依赖、打开即玩的科普向网页小游戏。它把核能领域最常见的公众误解，做成了一条条社交媒体风格的「谣言贴」，让玩家通过判断与操作，主动完成一次核科学知识的「纠错」。

游戏包含两个互补的模式：

- **🔍 打假模式** —— 读一条谣言，从两张科普卡片中拖出正确的那张，用科学事实「打脸」谣言；
- **🏗️ 市长模式** —— 按正确顺序建造压力容器、一回路、二回路、三回路与安全壳，在拼装中理解压水堆的内部结构。

项目为「数字媒体科技大赛」参赛作品，使用原生 HTML / CSS / JavaScript 编写，没有任何框架、构建步骤或后端依赖。

## 🕹️ 玩法说明

### 开始游戏

打开页面 → 点击 **「▶ 开始游戏」** → 选择 **打假模式** 或 **市长模式**。游戏过程中可随时点击右上角的 **「切换模式」**。

### 🔍 打假模式

1. 屏幕上方是一条社交媒体风格的谣言帖，下方会陆续弹出几条「路人评论」营造氛围；
2. 底部卡牌区出现 **2 张科普卡片**，其中一张是对该谣言的正解，另一张是随机干扰项；
3. 把认为正确的卡片**拖到任意位置松手**即可提交答案；
4. 无论对错，都会弹出对应的科学解释；点击「继续」进入下一条谣言；
5. 12 条谣言全部通关后结算并重置。

> 💡 答错不会卡关，弹出的科普解释才是这个模式真正的「奖励」。

### 🏗️ 市长模式

1. 主区域是一张灰度化的核电站剖面图，底部有 12 张卡牌（5 张真实结构 + 7 张干扰项）；
2. 必须按 **压力容器 → 一回路 → 二回路 → 三回路 → 安全壳** 的顺序建造；
3. 顺序正确时对应部件点亮，并弹出该部件的功能说明；
4. 5 个核心结构全部建成即通关，随后自动重置以便重新挑战。

### ⚡ 计分规则

| 场景 | 分值 |
| --- | --- |
| 打假模式 · 选中正确科普卡片 | **+10** |
| 打假模式 · 选中错误卡片 | **−5** |
| 市长模式 · 按顺序建成正确结构 | **+10** |
| 市长模式 · 建成顺序错误 | **−10**（最低扣到 0） |
| 市长模式 · 拖入干扰卡牌 | **−10**（最低扣到 0） |

分数在两个模式间共享并显示在顶栏；切换模式会重置市长模式的建造进度，但不会清空分数。

## 🧠 科普内容

### 谣言题库（12 条）

题库覆盖日常电磁辐射、核电站选址与水质、事故风险、核武器误解、医疗检查、孕妇防辐射等高频话题。

| # | 谣言关键词 | 一句话正解 |
| --- | --- | --- |
| 1 | 微波炉加热食物有辐射 | 微波属**非电离辐射**，能量不足以电离原子，食物不会带上放射性 |
| 2 | 小区基站辐射害人 | 基站同样是**非电离辐射**，且随距离快速衰减，远低于安全限值 |
| 3 | 核电站旁住不得 | 压水堆采用三回路多级隔离，**正常运行不向外界释放**放射性物质 |
| 4 | 核电站建好后自来水有怪味 | 排向外界的三回路水**从未接触**放射性物质，不会污染水源 |
| 5 | 核电站排废水，海鲜不能吃 | 正常运行不排放放射性废水，三回路水不带放射性 |
| 6 | 一旦泄漏就全完了 | **纵深防御**：燃料包壳、压力容器、安全壳构成三道实体屏障 |
| 7 | 会不会重演切尔诺贝利 | 该事故源于**设计缺陷 + 违规操作**；现代堆型有安全壳、负空泡系数与严格规程 |
| 8 | 核电站多了，事故难免 | 封闭安全壳、规章制度与人员培训共同杜绝同类事故 |
| 9 | 核电站就是原子弹 | 核电用 **3%–5% 低浓铀**，原子弹需 90% 以上武器级铀，且链式反应受控 |
| 10 | 医院拍片辐射巨大 | 单次胸片约 **0.1–0.3 mSv**，远低于公众年剂量限值 |
| 11 | CT 做了反而得病 | 单次 CT 剂量在安全范围内，临床获益大于风险 |
| 12 | 孕妇必须穿防辐射服 | 日常非电离辐射能量极低；人体每分钟约 4000 次钾-40 天然衰变，本就「泡」在天然辐射里 |

### 三回路小课堂

市长模式拼装的就是这套结构，也是理解「核电站为什么安全」的关键：

| 回路 | 是否带放射性 | 作用 |
| --- | --- | --- |
| **一回路** | 带放射性，但**完全封闭** | 把堆芯热量带到蒸汽发生器 |
| **二回路** | 不带放射性 | 受热产生蒸汽，推动汽轮机发电 |
| **三回路** | **完全不带放射性** | 冷却冷凝器，是唯一排向外界的部分 |

再加上**压力容器**（容纳堆芯、维持高压）与**安全壳**（隔离放射性物质），就构成了核电站的五项核心结构。

## 🚀 快速开始

### 方式一：直接打开

下载或克隆本项目，双击 `index.html` 即可游玩，无需安装任何依赖。

```bash
git clone https://github.com/<your-name>/<your-repo>.git
cd <your-repo>
```

### 方式二：本地静态服务器（推荐）

部分浏览器对 `file://` 协议下的字体与资源加载有额外限制，用本地服务器体验更完整：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 <http://localhost:8000>。

> ⚠️ 请确保 `index.html` 与 `img/` 目录保持在同一层级，否则背景图与结构图会加载失败。

## 🌐 部署到 GitHub Pages

本项目是纯静态站点，不需要任何构建步骤：

1. 新建 GitHub 仓库，把 **`index.html`、`style.css`、`main.js`、`rumors.js`、`city.js` 与 `img/`** 上传到**仓库根目录**（`index.html` 必须位于根目录，而不是嵌套在子文件夹里）；
2. 进入仓库 **Settings → Pages**；
3. **Build and deployment → Source** 选择 **Deploy from a branch**；
4. **Branch** 选择 `main`，目录选择 **`/ (root)`**，点击 **Save**；
5. 等待 1–2 分钟，访问 `https://<your-name>.github.io/<your-repo>/`。

如果希望把项目放在仓库的子目录中，请把 Pages 的目录改为 `/docs` 并把文件移入 `docs/`，或直接调整目录结构，确保页面入口与资源路径一致。

### 文件职责

## 🛠️ 技术实现

- **原生三件套**：无框架、无打包工具、无 `node_modules`，克隆即运行；
- **Web Audio API**：用振荡器（`OscillatorNode`）与增益包络实时合成 5 种音效，避免加载音频资源；
- **HTML5 Drag & Drop**：`draggable` 卡片配合 `dragstart` / `dragend` 实现作答反馈；
- **CSS 动画与过渡**：`@keyframes` 负责入场与辉光，`transition` 负责界面交叉淡入与弹框弹跳；
- **响应式**：`clamp()` 控制标题字号，`@media` 在 768px / 480px 两个断点重排布局；
- **字体**：通过 Google Fonts 引入 Noto Sans SC，离线时自动回退到「微软雅黑」。

## ✏️ 自定义与扩展

### 添加一条谣言

在 `rumors.js` 的数组中追加一项即可，`id` 需唯一且连续：

```js
{
  id: 13,
  text: "社交媒体上的谣言原文……",
  card: "作为正确答案的科普卡片文案（简洁、可判定）",
  knowledge: "答对 / 答错后弹出的完整科学解释。"
}
```

游戏会自动把新题目纳入随机抽题与通关判定，无需改动 `main.js`。

### 调整核电站部件

编辑 `city.js` 中每个结构的 `x` / `y` / `z` / `w` 即可微调位置、层级与大小；图片放到 `img/` 并更新 `img` 字段。

> 注意：`main.js` 中的 `cityCards` 决定了建造顺序与部件说明，增删部件时需同步修改这里，以及通关所需的 `cityProgress === 5` 判定。

### 调整计分

分数逻辑集中在 `main.js`：打假模式在卡片的 `ondragend` 中处理，市长模式在 `handleCityCardDrop()` 中处理。
