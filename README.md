# 核纪元 · 认知档案

交互式核科学科普项目。认知档案包含 8 章，章节阅读、小游戏、知识卡与结业证书使用同一套本地存档。

## 认知档案

| 章节 | 主要内容与交互 |
| --- | --- |
| 第一章：总览 | 三道开卷前测 + 初始态度 + 八章学习路线 + 压缩版历史叙事 |
| 第二章：国家安全 | 历史科普、封闭抽象外观旋转与三张知识卡 |
| 第三章：创新前沿 | 科研委托台：为研究任务选择合适装置，说明理由，理解能力与局限 |
| 第四章：百姓平安 | 核技术生活服务站：医院 / 食品 / 工业三个案例，判断用途、查看依据、解释原因 |
| 第五章：清洁能源 | 拼装压水堆后进入「追踪一度电」：连接能量路径，判断汽轮机 / 发电机作用 |
| 第六章：绿水青山 | 四重屏障组装：每放一层判断作用，最后把四张作用卡对应到模型 |
| 第七章：辐射防护 | 防护原理体验：外照射调时间 / 距离 / 屏蔽，内照射选防护动作，再解释原因 |
| 终章 | 公众科普回应：结论 + 依据两步判断，汇总已掌握 / 已纠正 / 建议复习，再完成认证 |

第二章的外观模型为抽象科普展品，不对应真实武器设计，不包含内部结构、拆解或装配。

第六章依次放入玻璃固化体、金属容器、缓冲与回填层、天然围岩。可以拖放，或点选后点击“放入”；模型支持旋转、缩放、分层展开及恢复视角。模型表达屏障的包含关系和作用，比例不代表工程尺寸。

第一章与第五、六章也增加了理解检查：

- 第一章：三道不公布答案的前测记录起点与初始态度；前测后展示八章学习路线；终章回看“前测 → 结业”和态度变化。
- 第五章：章节内聚焦 7 个核心部件拼装压水堆（完整 12 部件挑战保留在独立实验室）；建好后进入「追踪一度电」，按顺序连接“核裂变热 → 一回路 → 蒸汽发生器 → 汽轮机 → 发电机 → 电网”，再判断汽轮机与发电机的能量转换作用。
- 第六章：每放入一层屏障先判断这层的主要作用；四层完成后，把四张作用卡对应到四层屏障，全部正确才完成本节。

第三至四章、第七章与终章不再是单一的选择题或辟谣玩法：

- 第三章：每项委托先选装置，再说明理由；反馈同时给出“能解决什么”和“局限与代价”。
- 第四章：每个生活案例按“识别用途 → 查看三条依据 → 解释原因”完成，答错可重试。
- 第七章：外照射场景需要同时调整时间、距离与屏蔽，达标后解释原理；内照射场景选择正确防护动作，再说明“阻止进入”的核心。
- 终章：每道公众提问都要选结论、再选支持结论的依据；答错会解释并允许纠正。全部完成后才进入认证，证书页会列出已掌握、已纠正与建议复习的内容。

## 运行

认知档案的上方提供「标准 / 大 / 特大」阅读字号（18 / 21 / 24px），开始前与学习中都可以调整，选择会保存在本机。正文和小结保留所选字号，长内容在区域内滚动，完成按钮保持可见。

第五章建造会明确列出当前剩余部件。安全壳可点击标题区域或拖入轮廓，也可点选部件后使用「放入」按钮；一回路贯通后仍需放入安全壳，才能进入后续建造。

不需要构建或安装依赖，也不请求 CDN。使用原生 ES Modules，需通过 HTTP(S) 访问；请勿用 `file://` 直接打开 `index.html`。在项目目录启动静态服务器：

```bash
python3 -m http.server 8000
```

访问 <http://localhost:8000>。服务器需正确返回 JavaScript 和 CSS 的 MIME 类型，普通静态托管即可，也支持仓库子目录部署。3D 渲染不受支持或上下文丢失时，新关卡会显示静态示意，仍可完成学习。第二章支持旋转按钮与键盘操作，第六章支持点选作为拖放的等价方式。

独立四重屏障预览：`labs/waste-barriers.html`。

## 发布

仓库管理员可在 GitHub 的 Settings → Pages 中选择 Deploy from a branch，分支选 `main`，目录选 `/ (root)`，保存后即可使用 <https://pig-7788.github.io/nuclearplsx/>。本项目不需要构建步骤。

## 流畅度

`index.html` 只包含页面外壳、基础样式及一个模块入口。首页只加载目录、存档摘要和首页所需数据；点击入口时，路由通过 `import()` 加载对应页面及依赖，并等待该页样式就绪。进入认知档案只加载章节文字，小游戏在进入实际关卡时再加载。

Three.js 使用本地 ES Module，不创建 `window.THREE`。只有第六章的四重屏障关卡或独立深地质处置实验室需要它；两处共享同一份库。第二章的外观展台使用独立的轻量 WebGL 实现。成功加载的模块与样式在本次访问中复用，不重复下载或注册。

切换页面立即清理旧场景；快速连续点击只显示最后选择的页面，迟到的加载和关卡回调不能覆盖当前界面或写入进度。加载失败会显示恢复入口，原有存档不变。

3D 场景在静止、滚出屏幕或切到后台时停止绘制；独立地质处置实验室的自动旋转需手动开启。重复设施合并绘制，高分屏使用有限的渲染像素预算。章节按整章批量测量分页，首次音效初始化安排在页面绘制之后。

## 进度

存档位于浏览器 `localStorage`，保留章节完成记录、小游戏结果、知识卡、前测结果与态度记录。终章只有在所有公众提问都完成“结论 + 依据”两步后，才会保存结业证书标志；答错后纠正的题目会写入“已纠正”，不会影响证书，但会记录在总结中。终章统计页会读取第一章前测，展示“前测答对 → 终章一次答对 / 经纠正”的对照。首页可以重置整个应用的进度。

跳过、返回章节一览、切换模块时会销毁正在运行的关卡；过期的完成回调不能再修改进度。重玩已完成的关卡不会重复计分。

## 测试

需要 Node.js 20 或更新版本，无需安装依赖：

```bash
node --test tests/*.test.cjs
```

回归测试覆盖目录与存档摘要、按需加载去重、样式等待、失败重试、快速导航竞态、首次音效的延后初始化和静音设置、主线关卡生命周期、完成回调去重、跳过与重试、窗口变化、证书保存、历史知识卡、四重屏障状态机，以及新增章节的关卡数据完整性（前测、学习路线、追踪一度电、逐层作用判断与最终配对）。

## 代码入口

- `assets/js/app.js`：唯一的 HTML 模块入口和启动失败提示。
- `assets/js/core.js`：存档、导航和公共界面。
- `assets/js/catalog.js`：不依赖具体页面实现的路由目录与章节摘要。
- `assets/js/routes.js`：各路由的动态 import 与样式声明。
- `assets/js/route-loader.js`、`assets/js/style-loader.js`：加载缓存、失败回收与固定样式顺序。
- `assets/js/lesson-loaders.js`：各小游戏的按需入口（含开卷前测、追踪一度电、生活服务站、防护原理体验、科研委托台）。
- `assets/js/modes/main.js`：章节阅读、分页、进度与关卡切换。
- `assets/js/main-plays.js`：小游戏注册、挂载与清理。
- `assets/js/data/stories/`：8 章的内容与关卡配置。
- `assets/js/games/history.js`：第二章历史展台。
- `assets/js/games/research-desk.js`：第三章科研委托台。
- `assets/js/games/life-service.js`：第四章核技术生活服务站。
- `assets/js/games/protection-lab.js`：第七章防护原理体验。
- `assets/js/games/cognition-pretest.js`：第一章开卷前测与初始态度。
- `assets/js/games/power-trace.js`：第五章「追踪一度电」能量路径与作用判断。
- `assets/js/games/final.js`：终章公众回应、认知总结、前测对照与结业认证。
- `assets/css/lessons.css`：新增互动关卡的共享样式。
- `assets/js/history-exhibit-scene.js`：封闭外观的 WebGL 展示。
- `assets/js/games/barriers.js`：第六章与独立四重屏障组件的适配。
- `assets/js/waste-barriers.js`：组装状态、说明与静态备用视图。
- `assets/js/waste-barrier-scene.js`：基于本地 Three.js 的 3D 剖面。
- `assets/vendor/three.module.js`：本地 Three.js 0.152.2 的 ES Module，许可见 `THREE-LICENSE.txt`。

页面仍保留辟谣实验室、核电站建造、反应堆控制台、剂量实验室、中国核电，以及主分支新增的独立深地质处置实验室（`#/repository`）。独立实验室将缓冲与回填材料分开展示为五层；第六章按课程要求合并为四重屏障。示意模型和典型剂量用于科普教育，不用于工程计算、真实操作训练或医疗判断。
